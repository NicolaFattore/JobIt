# JobIt Application

## Testing

### Running Tests
To run tests, use the following npm scripts:

- Run all tests: `npm test`
- Run tests in watch mode: `npm run test:watch`
- Generate coverage report: `npm run test:coverage`

### Test Configuration
- Framework: Jest
- Preprocessor: ts-jest
- Environment: Node.js

### Writing Tests
- Place test files in `__tests__` directory
- Use `.test.ts` or `.spec.ts` file extensions
- Import the functions/components you want to test
- Use Jest's testing methods like `describe`, `test`, `expect`

## Development Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Run tests: `npm test`
4. Start development server: `npm run dev`
